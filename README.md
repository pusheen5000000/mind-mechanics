# Mind-Mechanics

A collection of minigames designed to teach and reinforce anxiety management skills, including thinking errors, relaxation exercises, general anxiety knowledge, and coping strategies. Built with HTML, CSS, and JavaScript, hosted on GitHub Pages.

## Games

1. **Thinking Errors**: Identify the correct thinking error to make the kitty happy.
2. **Relaxation**: Pick up car parts with a basket to unlock a relaxation exercise.
3. **Anxiety Review**: Go fishing and answer general questions about anxiety.
4. **Quiz Race**: Two-player race to the finish line, answering questions about anxiety and thinking traps.
5. **Jeopardy**: Classic Jeopardy-style quiz covering anxiety topics.
6. **Matching**: Match each thinking trap term to its correct definition.

## Folder Structure

```
games/
├── anxiety-review/
├── jeopardy/
```

Each game folder contains its own `index.html`, `script.js`, `style.css`, and `images/`.
